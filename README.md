# 🌱 FoodLoop — Smart Campus Food Rescue Network

FoodLoop is a sustainability-focused campus food rescue platform designed to connect food providers with student volunteers and reduce avoidable food waste.

## 🎯 Problem Statement

Campus cafeterias, hostels and food outlets often have surplus freshly prepared food. Without timely coordination, this food may go unused.

## 💡 Proposed Solution

FoodLoop provides a centralized platform where campus kitchens can post surplus food and volunteers can discover and claim available food before its collection deadline.

## ✨ Key Features

- Post surplus food listings
- Search and filter food availability
- Smart Priority Engine
- Food expiry countdown
- Volunteer food claiming
- Undo last five actions
- Dynamic sustainability statistics
- Campus rescue network visualization
- Activity history
- Responsive interface

## 🧠 Smart Priority Engine

Food listings receive priority based on their remaining collection time. This helps volunteers identify urgent food listings first.

## 🔄 Workflow

1. Food providers post surplus food.
2. FoodLoop calculates collection urgency.
3. Volunteers discover available listings.
4. Volunteers claim food for collection.
5. Impact statistics reflect successful rescues.

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 Run Locally

1. Clone this repository.
2. Open the FoodLoop folder in VS Code.
3. Open `index.html` using Live Server.
